# macOS Native Design

Design, critique, and scaffold native macOS apps — HIG, Liquid Glass, menus, toolbars,
sidebars, safe areas, accessibility, SwiftUI/AppKit. Command: `/macos-design`.

**Author:** [Robert Courson](https://robertcourson.com) · Part of [Robert's Skills](https://github.com/robzilla1738/roberts-skills)

---

## Install

### Claude Code (plugin)

```text
/plugin marketplace add robzilla1738/roberts-skills
/plugin install macos-design@roberts-skills
```

Then use `/macos-design`.

### Cursor / Codex

```bash
cp -R plugins/macos-design/skills/macos-design ~/.agents/skills/   # Cursor + Codex
cp -R plugins/macos-design/skills/macos-design ~/.cursor/skills/   # Cursor
```

See [`skills/macos-design/`](skills/macos-design/) for the hub and reference spokes.
