# Web Marketing Landing

Design and scaffold a premium SaaS marketing home page — aurora hero, glass nav, connector
hub, bento grid, CSS motion — on Next.js + Tailwind v4.

**Author:** [Robert Courson](https://robertcourson.com) · Part of [Robert's Skills](https://github.com/robzilla1738/roberts-skills)

---

## Install

### Claude Code (plugin)

```text
/plugin marketplace add robzilla1738/roberts-skills
/plugin install web-marketing-landing@roberts-skills
```

Then use `/landing-page`.

### Cursor / Codex

```bash
cp -R plugins/web-marketing-landing/skills/web-marketing-landing ~/.agents/skills/   # Cursor + Codex
cp -R plugins/web-marketing-landing/skills/web-marketing-landing ~/.cursor/skills/   # Cursor
```

See [`skills/web-marketing-landing/`](skills/web-marketing-landing/) for the hub and spokes.
